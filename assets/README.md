# Build resources

Place platform icons here before running `npm run dist`:

| File | Platform |
|------|----------|
| `icon.ico` | Windows |
| `icon.icns` | macOS |
| `icons/` (PNG sizes) | Linux |

A single `icon.png` (512×512 or larger) can be used as a source to generate platform icons.

If no icon is provided, electron-builder uses the default Electron icon.
